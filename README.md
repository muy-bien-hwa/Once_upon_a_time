# Once upon a time (옛날 옛적에)

> 한 문장씩 이어 쓰는 분기형 릴레이 스토리 웹앱 · 🚧 개발 중

- 누구나 문장(최대 100자)을 이어 써서 이야기를 만든다
- 한 문장 뒤에 여러 문장이 이어지면서 이야기가 가지처럼 갈라진다
- 목표: 가장 많은 작가가 함께 쓴 이야기에 도전

## Stack
- Frontend: React (Vite)
- Backend: FastAPI · PostgreSQL · SQLAlchemy · Alembic

## Structure
- [`backend/`](backend/README.md): API 서버
